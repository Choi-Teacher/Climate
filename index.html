선생님용 · Supabase 설정과 SQL 스키마

무료 Supabase 프로젝트 하나면 반 전체가 실시간 거래·클라우드 세이브·구경 가기를 쓸 수 있습니다. Project URL과 anon key를 복사해 위 '선생님' 모드에 넣고, SQL 편집기에서 아래 표를 한 번 만드세요.

-- [V4] 같은 방·같은 기후의 학생들이 하나의 월드(edits)를 공유합니다. create table if not exists offers (id text primary key, room text, biome text, trader text, give jsonb, want jsonb, status text default 'open', taker text, claimed boolean default false, ts timestamptz default now()); create table if not exists roster (room text, name text, biome text, primary key (room,name)); -- 월드: (room,biome) 단위 공유. seed/edits 를 같은 기후 학생들이 함께 씀 create table if not exists worlds (room text, biome text, seed int8, edits jsonb, day int, snap timestamptz default now(), primary key (room,biome)); -- 플레이어: 개인 인벤토리·스탯은 (room,name) 별도 저장 create table if not exists players (room text, name text, biome text, inv jsonb, stat jsonb, pos jsonb, day int, snap timestamptz default now(), primary key (room,name)); alter table offers enable row level security; alter table roster enable row level security; alter table worlds enable row level security; alter table players enable row level security; create policy anon_offers on offers for all using(true) with check(true); create policy anon_roster on roster for all using(true) with check(true); create policy anon_worlds on worlds for all using(true) with check(true); create policy anon_players on players for all using(true) with check(true); -- 실시간(블록 동기화·아바타)은 Supabase Realtime Broadcast를 씁니다. 추가 테이블/설정 불필요.
