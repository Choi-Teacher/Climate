👥 배정 명단 0명

처음 한 번만 하는 서버 준비

서버 주소와 키는 앱에 내장되어 있어 아무도 입력하지 않습니다. 개발자가 .env에 한 번 넣어 배포하면 반 전체가 같은 서버를 씁니다. 데이터베이스 쪽은 아래 세 가지만 한 번 해 두면 됩니다.

1. Supabase 대시보드 → Authentication → Sign In / Providers 에서 Anonymous sign-ins를 켭니다. 학생마다 익명 계정이 발급되고, 이 계정이 있어야 “내 데이터만 내가 고친다”는 규칙(RLS)이 실제로 작동합니다.

2. Authentication → Rate Limits 에서 익명 로그인 한도를 시간당 30회보다 넉넉하게(예: 200) 올립니다. 학교는 한 IP를 다 같이 쓰기 때문에 기본값이면 한 반이 다 접속하지 못합니다.

3. SQL Editor에 함께 배포된 schema.sql 전체를 붙여넣고 실행합니다. 표와 접근 규칙(RLS)이 한 번에 만들어집니다. 마지막에 선생님 계정을 teachers 표에 넣는 줄이 있으니 이메일만 바꿔 주세요.

선생님 계정은 Authentication → Users → Add user에서 이메일·비밀번호로 하나 만들면 됩니다. 이 계정으로 로그인해야 명단을 저장하고 학생 데이터를 정리할 수 있습니다.
